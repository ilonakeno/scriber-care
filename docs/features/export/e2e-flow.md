# Експорт протоколу: наскрізний потік

1. Лікар переглянув і відредагував протокол (`docs/features/protocol-generation/`).
2. Лікар обирає, куди забрати протокол: Word, PDF або копіювання тексту для МІС.
3. **Word:** формується редагований файл .docx із поточної версії протоколу. **PDF:** формується фіксований файл для друку чи пересилання.
4. Файл завантажується в браузер. На комп'ютері він потрапляє в «Завантаження», на iPhone в Safari: «Файли», далі «Завантаження».
5. Word при відкритті файлу з інтернету може показати «Захищений перегляд»: щоб редагувати, потрібно натиснути «Дозволити редагування».
6. **Для МІС:** лікар копіює текст і вставляє в поле МІС. Прямої інтеграції нема, вставка вручну.
7. Багато МІС приймають лише простий текст. Тому для вставки використовуй «Вставити як звичайний текст» (наприклад, Ctrl+Shift+V) або експорт без форматування, інакше таблиці й шрифти Word ламаються.
8. Лікар виправив протокол після експорту: у старому файлі змін нема. Потрібен повторний експорт.
9. Файл не завантажився чи загубився: `resend_export` повторно надсилає Word або PDF власнику акаунта.
10. Лікар перевіряє, що в МІС чи файлі все відображається правильно, і лише тоді передає документ далі.
11. Запит надіслати експорт на іншу адресу, видалити файл чи показати протокол пацієнта: P0, `escalate_to_human`.
